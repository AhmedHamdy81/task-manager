Fill down

Some day-level values are written only on the first row of each group. Fill-down carries a value to the blank cells below it in the same worksheet. It never fills upward or overwrites a value, and it stops at blank, summary and repeated-header rows. A new Day starts without the previous Day's Location and Date. Inherited values are marked in the preview.
